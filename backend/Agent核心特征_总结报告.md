# Agent 核心特征 —— 收集与总结报告

## 一、权威定义对照

| 来源 | 定义要点 |
|------|----------|
| **Russell & Norvig《AI: A Modern Approach》** | 智能体(Agent) = 一切都是感知输入的函数，通过执行器作用于环境；好的智能体应最大化"性能度量" |
| **Wooldridge（《多智能体系统导论》）** | Agent 是能够自行行动的计算机系统，具有社会性、自主性、反应性、主动性四大经典特征 |
| **BDI 模型（Bratman）** | Agent 心智状态由信念(Belief)-愿望(Desire)-意图(Intention)构成，决策即意图的履行与调整 |
| **通用工程定义** | Agent = 感知(Perception) -> 规划(Planning) -> 行动(Action)的闭环 |

---

## 二、四大核心特征(详细版)

### 1. 自主性(Autonomy)
- **本质**: 行为不受外部直接控制，由内部状态和策略驱动
- **三层含义**:
  - **行为自主**: 无需人类逐步指令(如 AutoGPT 自主拆解任务)
  - **状态自主**: 内部记忆/状态的维护与管理自己完成
  - **目标自主**: 主动设定/调整子目标(非完全预设)
- **度量维度**: 干预频率(人类多久需要纠正一次)、任务完整度(端到端完成率)

### 2. 感知(Perception)
- **三种模态**:
  - **物理感知**: 传感器(摄像头、麦克风、激光雷达)
  - **数字感知**: API 返回、文件、数据库、网页抓取
  - **社会感知**: 用户对话、其他 Agent 的消息、环境反馈信号
- **现代扩展(LLM Agent)**:
  - 感知对象不仅是数据，还包括**自然语言指令**、**工具返回结果**、**隐式上下文**(如会话历史)
  - 感知质量直接决定决策上限("垃圾进，垃圾出"原则)

### 3. 决策(Decision-Making)
- **决策层次**:
  - 战略层(目标选择) -> 战术层(方案规划) -> 执行层(动作序列)
- **主流决策范式**:
  | 范式 | 代表方法 | 特点 |
  |------|----------|------|
  | 符号推理 | 规则机、专家系统 | 可解释性强，扩展性弱 |
  | 状态搜索 | 规划算法(PDDL、A*)、博弈搜索 | 适合明确目标 |
  | 数据驱动 | 深度学习策略、LLM 推理 | 泛化能力强，黑盒 |
  | 强化学习 | Q-Learning、策略梯度、RLHF | 自适应最优，需 exploration |
  | 大模型 Agent | ReAct、Plan-and-Execute、CoT | 新兴范式，工具增强 |
- **关键属性**: 目标导向性、可适应性(根据反馈修正)、不确定性下的鲁棒性

### 4. 执行(Action / Actuation)
- **执行对象**: 对**环境**施加改变
- **执行类型**:
  - 物理执行: 机器人关节、机械臂、无人机
  - 数字执行: 调用 API、运行代码、数据库写入、发送消息
  - 交互执行: GUI 操作、API 调用、人机对话
- **执行质量要求**:
  - **有效性**: 行动确实达成预期效果
  - **安全性**: 对环境的副作用可控
  - **可观测**: 执行结果可被重新感知(错误恢复的前提)

---

## 三、四大核心特征的关系(闭环模型)

    感知(Perception) -> 决策(Decision) -> 执行(Action)
         ^                                          |
         |______ 环境反馈(Environment Feedback) ______|

- **自主性**是贯穿整个闭环的控制中枢: 感知什么、如何决策、何时执行，都由 Agent 自身决定
- 闭环的每一次迭代，就是 Agent [感知-决策-执行-再感知]的一个**周期(cycle)**

## 四、补充特征(广义 Agent 还应具备)

| 特征 | 说明 | 学术名称 |
|------|------|----------|
| **反应性(Reactivity)** | 对环境变化做出及时响应 | Wooldridge 经典四性之一 |
| **主动性(Proactiveness)** | 主动追求目标而非被动响应 | Wooldridge 经典四性之一 |
| **社会性(Social Ability)** | 与其他 Agent / 人类协作 | 多智能体系统必备 |
| **学习性(Learning)** | 通过经验改进策略 | 强化学习、持续学习 |
| **记忆性(Memory)** | 短期记忆(工作记忆) + 长期记忆(知识库/RAG) | 大模型 Agent 必备 |
| **可解释性(Explainability)** | 决策过程可追溯、可审计 | 关键场景(医疗、金融)必备 |
| **安全性(Safety)** | 对齐人类意图，避免有害行为 | LLM Agent 时代的核心议题 |

## 五、不同类型 Agent 特征对比

| Agent 类型 | 自主性 | 感知复杂度 | 决策方式 | 执行方式 | 典型代表 |
|-----------|--------|----------|----------|----------|----------|
| **反应型(Reactive)** | 低 | 简单 | 规则匹配 | 简单动作 | 温控器、工业机器人 |
| **认知型(Deliberative)** | 高 | 复杂 | 符号推理/搜索 | 复杂动作 | 自动驾驶、DeepBlue |
| **学习型(Learning)** | 高 | 持续 | RL / ML 模型 | 自适应 | AlphaGo、推荐系统 |
| **大模型 Agent(LLM-based)** | 中-高 | 自然语言+工具接口 | CoT / ReAct / 规划 | API 调用 + 代码执行 | AutoGPT、Devin、Manus |
| **多智能体(Multi-Agent)** | 高 | 分布式 | 协作推理 | 协同执行 | 智能交通、集群机器人 |

## 六、LLM Agent 时代的新特征(补充)

随着大语言模型的发展，Agent 的核心特征发生了重要演进:

1. **语言成为核心感知与执行通道**: LLM Agent 的感知主要是自然语言理解，执行主要是通过语言调用工具(function calling)
2. **工具使用(Tool Use)成为执行能力的扩展**: 搜索、代码执行、数据库查询等外部能力被封装为"工具"
3. **规划能力显性化**: ReAct（推理+行动交替） / Plan-and-Execute（先全局规划再逐步执行） / Tree of Thoughts（多候选方案并行探索）
4. **长程记忆与上下文管理**: 短期=工作记忆(context window)；长期=向量数据库/RAG
5. **人机协作的新范式**: 人类角色从"发号施令"转向"设定目标 + 审核结果"

## 七、总结: 四大特征一句话定义

| 特征 | 一句话定义 |
|------|------------|
| **自主性** | Agent 能够独立决定"做什么"和"怎么做" |
| **感知** | Agent 能够通过传感器/接口获取环境信息 |
| **决策** | Agent 能够基于感知信息和内部状态选择最优行动 |
| **执行** | Agent 能够将决策转化为对环境的实际改变 |

核心结论: 真正意义上的 Agent, 不是单一算法或模型, 而是**自主性 + 感知 + 决策 + 执行**四者组成的完整闭环系统。其中**自主性**是灵魂, **感知**是输入, **决策**是大脑, **执行**是输出——缺一不可。
