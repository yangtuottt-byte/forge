# Agent（智能体）的核心定义与关键特征

> 资料来源：综合主流 AI 教材（如 Russell & Norvig《人工智能：一种现代方法》）与近年大模型智能体研究。

## 一、最核心的定义

**Agent（智能体）**：能够**感知环境 → 自主决策 → 执行行动**，以达成特定目标的"自主实体"。它可以是软件程序，也可以是机器人等物理实体。

- 经典运作模型：**"感知—决策—行动"循环（Perception–Decision–Action Loop）**
- 数学化描述：在每个时间步 t，Agent 接收观察 O_t（感知），执行动作 a_t（决策输出），目标是最大化长期累积奖励（强化学习框架）或达成目标状态（规划框架）。

## 二、关键特征（六大核心属性）

1. **自主性 Autonomy**：无需人工逐项干预，能独立控制行为并制定策略
2. **感知能力 Perception**：通过传感器/输入通道（文本、图像、API 数据等）获取环境状态
3. **决策能力 Decision-making**：基于感知信息与内部知识进行推理、规划、搜索
4. **执行/行动能力 Action**：通过效应器/输出通道（执行代码、调用 API、机器人关节）影响环境
5. **目标导向 Goal-oriented**：行为围绕显式或隐式目标展开，强调结果达成
6. **学习与改进能力 Learning**：从经验中调整策略，越用越好

补充：Russell & Norvig 还强调**社会性（Social ability，能与其他 Agent/人类协作）**与**理性（Rationality：在给定知识下做出使目标达成概率最大化的选择）**。

## 三、理性（Rationality）概念

Agent 应是"理性的"：在自身感知与知识的约束下，选择最有可能达成目标的行动。这是区分"会动的东西"与"智能体"的本质标准——行动必须有意图，而不仅是机械反应。

## 四、Agent 的设计框架：PEAS

1. **P (Performance) 性能度量**：如何衡量成功（任务完成度、耗时、成本）
2. **E (Environment) 环境**：Agent 所处的环境（物理/虚拟/多用户/确定性/随机性）
3. **A (Actuators) 执行器**：Agent 能做什么动作
4. **S (Sensors) 传感器**：Agent 能观察什么

## 五、经典分类（按智能体架构复杂度递增）

1. 简单反射 Agent：当前感知 + IF-THEN 规则，无内部状态
2. 模型反射 Agent：维护内部状态模型，处理部分可观测环境
3. 目标导向 Agent：拥有明确目标，通过搜索/规划选择动作
4. 效用导向 Agent：引入效用函数，在多个目标间权衡最优解
5. 学习型 Agent：从经验中改进绩效，能力最强

## 六、现代大模型智能体（LLM-based Agent）的核心特征

- 核心大脑：LLM 承担推理引擎
- 感知入口：自然语言指令、多模态、环境状态
- 规划能力：任务分解、子目标生成、思维链、反思（Reflection）
- 工具使用：调用 API、搜索引擎、数据库、计算器、代码解释器
- 记忆系统：短期上下文 + 长期向量数据库/文件系统
- 反馈循环：观察执行结果 → 自我修正 → 迭代优化

## 七、与其他概念的区别

- **传统自动化脚本**：固定流程、无自主决策；Agent 能动态规划
- **LLM 本身**：只提供推理能力，不是完整 Agent；Agent 需要感知+行动+反馈闭环
- **RPA**：依赖预定义规则，无法处理开放域任务；Agent 具备自主性

## 一句话总结

> Agent 的本质：以"感知—决策—行动"为闭环，以自主性与目标导向为核心特征，能够持续与环境交互、独立达成目标的智能实体。
