# 🏗️ 项目驱动学习路径:Forge 多智能体协作研发平台

> 方式:**做一个真实项目,边做边学知识点**(不做"先啃概念再动手")
> 项目:多智能体协作研发平台 —— 用户提交研发任务,多个 Agent 分工协作完成,生产级后端支撑
> 制定日期:2026-11-04
> 对应知识点:Agent 开发全部 + 后端工程能力(计算机基础/语言深度/数据库/分布式/架构/排障/工程化/业务)

---

## 🎯 为什么是这个项目

| 维度 | 说明 |
|------|------|
| 能力覆盖 | Agent 开发全部(多 Agent/规划/记忆/工具/MCP/HITL/评估) + 后端工程全栈(DB/缓存/队列/实时/认证/可观测/微服务) |
| 面试友好 | "分布式 Agent 系统怎么设计""多 Agent 怎么协调""代码沙箱怎么隔离"都是高频追问 |
| 发挥优势 | 有后端部分(FastAPI/DB/队列/微服务),用上你的后端经验,兼顾工程深度 |
| 旗舰定位 | 不是小 demo,是能证明"具备资深工程师 + AI Agent 全栈能力"的旗舰项目 |
| 范围可控 | 分 6 个阶段,每阶段有可交付成果,逐步吃下这个大象 |

## 🧱 技术栈选型(我帮你定好,你不用纠结)

| 模块 | 选型 | 为什么 |
|------|------|--------|
| LLM API | OpenAI 兼容接口(讯飞星火 / DeepSeek 等) | 生态成熟,一套通吃 |
| Agent 框架 | 原生手写 + LangGraph(对比) | 先懂原理,再用框架 |
| 规划 | ReAct / Plan-and-Execute | 任务拆解 |
| 记忆 | 短期(内存) + 长期(PostgreSQL+PGVector) | 分层记忆 |
| 工具生态 | 自定义工具 + MCP(Model Context Protocol) | 标准工具接口 |
| 代码执行 | 沙箱(进程/namespace 隔离) | 安全隔离 |
| Web 框架 | FastAPI | 你后端熟 |
| 数据库 | PostgreSQL + PGVector | 关系+向量一体 |
| 缓存 | Redis | 缓存/队列/分布式锁/pub-sub |
| 异步队列 | Celery | 后台跑 Agent 任务 |
| 实时通信 | WebSocket | Agent 进度实时推送 |
| 可观测 | logging + metrics + 链路追踪 | 生产必备 |
| 部署 | Docker Compose(→ 可选 k8s) | 多服务编排 |
| 配置 | pydantic-settings + .env | 密钥不入 Git |

## 📌 各阶段知识点展开(做哪次展开哪次)

### 阶段 0:项目初始化 ✅
- 仓库规范(Conventional Commits、trunk-based)
- CI/CD 流水线(lint + test)
- 目录骨架、Makefile、.gitignore
- README、迭代路线图

### 阶段 1:后端地基
- pydantic-settings 配置注入(分层:dev/prod)
- PostgreSQL + SQLAlchemy + Alembic 迁移
- JWT 认证 + RBAC 权限
- Redis 缓存 + 分布式锁
- 分层架构:api → service → repository → model
- 依赖注入、生命周期管理

### 阶段 2:Agent 核心
- Agent 基类设计(消息、状态、记忆接口)
- 单 Agent + Function Calling
- 规划:ReAct / Plan-and-Execute(任务拆解)
- 记忆:短期(内存) + 长期(PGVector)
- 流式输出(Agent 过程实时展示)

### 阶段 3:多 Agent 协作
- 角色定义(规划者/研究员/执行者/审查员)
- 协调器(任务分派、消息传递)
- LangGraph 状态机(对比原生实现)
- Human-in-the-loop(人工审批节点)
- 多 Agent 冲突解决

### 阶段 4:工具生态 + MCP
- 工具注册机制(schema + 分发)
- MCP(Model Context Protocol)标准接口
- 工具:搜索 / 代码执行 / 文件操作
- 代码沙箱(进程/namespace 隔离,防逃逸)
- 工具权限与安全

### 阶段 5:异步 + 实时
- Celery 队列 + 多 worker
- 任务状态持久化(PostgreSQL)
- WebSocket 实时进度推送
- 分布式锁(防任务重复执行)
- 任务幂等、重试、死信队列

### 阶段 6:生产化
- 可观测:日志(logging)、指标(metrics)、链路追踪
- 限流、输入校验、安全加固
- 测试补全(unit/integration/e2e)
- CI/CD 完善、Docker Compose 多服务
- 架构文档、ADR、性能优化
